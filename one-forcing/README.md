# One-Forcing Project Page

Static GitHub Pages site for the One-Forcing paper.

## Local preview

```bash
python3 -m http.server 8000 --directory project_page
```

Then open `http://127.0.0.1:8000/`.

## GitHub Pages

This directory is self-contained. Publish it from the repository root, a `docs/`
directory, or a `gh-pages` branch as long as `index.html` is at the publishing
root.
